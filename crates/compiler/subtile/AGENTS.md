# crates/compiler/subtile (scratchy-subtile)

## OVERVIEW
The target-neutral IR, tape, and shared passes (reroll, colouring, folding, KV codec) that metal and spyre both use. It's a plain lib, so it can be unit-tested on any host. Score ~22 (15 modules, 16k LOC, 17 integration tests, own build.rs).

## FLOW
`lower::LoweringInput` (plain-data mirror of the macro's Fuf+Assignment) -> `subtile_ir::lower_region` (SSA DAG of `SubOp`) -> `subtile_tape::lower_dag_to_tape` / `reroll_subtile_tape` -> `tape_colouring` / `tape_folding` / `kv_codec` / `sample_rows` -> `handoff` types the targets consume.

## WHERE TO LOOK
| Task | Location | Notes |
|------|----------|-------|
| Add an op | `subtile_ir.rs` `SubOp` | matches are enumerated: a new variant must break the build |
| Layer loop detection | `subtile_tape.rs` `find_layer_loop` | the ONE search; the macro calls it |
| Arena slot sharing | `tape_colouring.rs` `ColourRule`, `ColourFacts` | target alias facts come in as input |
| Kernel fusion | `tape_folding.rs` `FusionTable`, `FoldPattern` | overlay keyed on `SlotId`; the tape itself isn't modified |
| KV codec insertion | `kv_codec.rs` `expand_kv_codec` | a geometry the kernels don't take is a no-op |
| Compiler->target types | `handoff.rs` `WeightId`, `TileId`, `SlotMap` | no `syn` (linked into the metal runtime) |
| Host transfers | `host_tape.rs` | transfers are STATED, never inferred |
| Model head geometry consts | `model_geometry.rs` `with_config_*` | generated by build.rs |
| Test input builders | `fixtures.rs` | always compiled |
| Spyre addressing | `addr`, `sdsc_abstract` re-exports | cfg `spyre`, from `ktir-superdsc` |

## CONVENTIONS
- Target-ABI facts arrive as const tables (`ColourFacts`, `FusionTable`, `KvCodecFacts`, `SampleRowsFacts`). `subtile_tape.rs:51` keeps a forbidden-token list: grepping for target tokens must return zero hits.
- Reroll and tape machinery are deliberately UNGATED so metal doesn't fork it. `spyre` gates only the bundle/SuperDSC re-exports and the attention-geometry door.
- Sealed handles (`SlotId`, `SlotHandle`, `SlotWritten`, `RopeForm`) are move-only. Double-write, read-before-write, and read-after-free fail to compile.
- Newtype witnesses replace primitive pairs and bools (e.g. "NOT A `(mult,div)` PAIR"). Keep them typed.
- `build.rs` reads every `crates/models/arch/*/configs/*.json` and writes `config_geometry.rs`. A new config re-triggers it via `rerun-if-changed`.
- Tests: names state the property. `zz_*` replays measured on-card bug sequences.
- `verus/` is a standalone proof module on its own pinned toolchain, outside cargo.

## ANTI-PATTERNS
- Hand-rolled stride or address formulas per model. Every address is an `addr::Nest` at a rank (`addr_shape_drives_addressing.rs`).
- Allocating inside a loop body (`subtile_tape.rs:606`).
- A second page allocator inside the worker: block tables come from the host only, and a short page list is REFUSED.
- Constructing `PaddedMq` width and pad separately. `Rung::<31>::baked()` must fail with E0080.
- Reviving `lower_subtile_tape_to_sengraph`: sengraph is a deleted dead end.
- Leaving a stale test file in `tests/`: it breaks `cargo test --tests` for everyone.

## COMMANDS
```bash
cargo test -p scratchy-subtile                    # CI, featureless
cargo test -p scratchy-subtile --features spyre   # CI, adds addr/sdsc tests
KANI_PKG=scratchy-subtile ~/.claude/bin/kani-safe.sh <harness> --features spyre
bash crates/compiler/subtile/verus/verify.sh      # needs rustup 1.96.0-aarch64-apple-darwin
```
Without `--features spyre`, Kani finds ZERO harnesses and reports "no harnesses matched", which reads like a typo. A proof that does not run is worse than none. `cfg(kani)` is declared in check-cfg, not silenced.
