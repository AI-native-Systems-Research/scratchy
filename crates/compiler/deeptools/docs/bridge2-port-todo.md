  `cargo build -Fsuperdsc,model/granite-3.1-2b-instruct,quant/fp8-dynamic-per-channel` going
  through, read from the `-vv` stream. There are no unit tests for this bridge.

- ⛔ **AUDIT MEANS LINE BY LINE.** Read the C++ and our Rust side by side and check every branch,
  every constant, every attribute name and value, every default, every early return, and the order
  of emission. Report divergences, including deliberate ones with their reason.
- ⛔ **NO REFUSALS, NO RUNTIME ASSERTS, NO DEBUG ASSERTS.** Closed sets are enums; invariants are

- ⛔ **NO GROUPING.** Each entry is ticked on its own or not at all.
